#  Day 01 — Dad Joke Generator😂

My first project of the **30 Days of Building** journey.

A simple web app that uses an API to fetch and display random dad jokes in a fun card-style interface.

### 🛠️ Built With

* HTML
* CSS
* JavaScript
* Python
* REST API

### 📚 What I Learned

* What APIs are and how they work
* Making API requests
* Working with JSON responses
* Using API data in JavaScript
* Fetching API data with Python
* Running a local web server

### ▶️ Run Locally

```bash
python -m http.server 8000
```

Open:

```text
http://127.0.0.1:8000/
```

### 📁 Files

```text
index.html
styles.css
script.js
Dad_joke_generator.py
```

### 💭 Day 01 Takeaway

Started with the basics: **making an API request, getting a response, and turning that data into something people can interact with.**
